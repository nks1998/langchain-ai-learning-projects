# AI Learning Projects

A collection of small LangChain, LangGraph, and Streamlit projects for learning how to build AI-powered applications with Google Gemini.

## What's in this repository

| Path | Contents |
| --- | --- |
| `apps/qna_bot.py` | AskBuddy, a basic Streamlit general-knowledge Q&A chatbot. |
| `apps/qna_bot_memory.py` | A Q&A chatbot that keeps conversation history during a session. |
| `apps/sql_bot.py` | TaskBot, a chat interface that manages tasks in a local SQLite database. |
| `notebooks/` | Experiments covering prompts, chat history, embeddings, vector databases, RAG, tools, and structured output. |
| `data/` | Sample PDFs, CSVs, and text files used in the notebook exercises. |
| `my_tasks.db` | Local SQLite database used by TaskBot. |
| `requirements.txt` | Python dependencies for the apps and notebooks. |

## Notebooks

The `notebooks/` directory contains hands-on experiments with LangChain and related AI application patterns.

| Notebook | Topic |
| --- | --- |
| `basic.ipynb` | Basic LangChain and Gemini model calls. |
| `chat_with_history.ipynb` | Maintaining chat history across messages. |
| `data_loader.ipynb` | Loading documents from PDFs, text, CSVs, and web sources. |
| `data_splitting.ipynb` | Splitting documents into chunks for retrieval. |
| `embedding.ipynb` | Creating vector embeddings for text. |
| `rag_pipeline.ipynb` | Retrieval-augmented generation (RAG) workflow. |
| `stream_resp.ipynb` | Streaming model responses. |
| `struct_out.ipynb` | Generating structured model output. |
| `tool_agent.ipynb` | Building an agent that can call tools. |
| `tools_memory.ipynb` | Combining agent tools with conversation memory. |
| `docker_model.ipynb` | Working with a model in a Docker-based workflow. |
| `new.ipynb` | Scratch notebook for additional experiments. |

`notebooks/myvector_db/` contains the persisted Chroma vector database generated by the embedding and RAG exercises.

## Setup

Requires Python 3.10 or later.

```bash
git clone <your-repository-url>
cd AI
python -m venv env
source env/bin/activate
python -m pip install -r requirements.txt
```

Create a `.env` file in the repository root with your Google AI API key:

```env
GOOGLE_API_KEY=your_google_ai_api_key
```

Never commit this file. It is excluded by `.gitignore`.

## Run an app

From the repository root, activate the environment and run one of these commands:

```bash
streamlit run apps/qna_bot.py
streamlit run apps/qna_bot_memory.py
streamlit run apps/sql_bot.py
```

Streamlit will print a local URL, normally `http://localhost:8501`, to open in your browser.

## Notes

- The apps use `langchain-google-genai` and require a valid Google Gemini API key.
- `sql_bot.py` creates the `tasks` table automatically in `my_tasks.db` when it starts.
- The local vector-database files in `notebooks/myvector_db/` are generated notebook data and can be recreated from the RAG experiments.
